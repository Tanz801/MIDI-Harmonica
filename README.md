This is a midi controller in the form of a harmonica. This was made for week 3 of Hack Club's half life, where the theme was to make an instrument. Chose to make a harmonica at the suggestion of a friend.

![harmonica cad](assets\HarmonicaCAD.png)

## Features
10 holes each with their own air pressure sensor
Joystick for pitch bends
Vibrato button
Pitch shift buttons
slider for texture selection
